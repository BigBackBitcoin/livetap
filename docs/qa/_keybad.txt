Name for this destination
Anything you will recognise in Studio, like “Late night build”.
Server address
The platform calls this the server or the URL.
That looks like a web page address, not a stream server. Stream servers start with rtmp:// or rtmps://.
Stream key
This is a password for your channel. LIVETAP keeps it for this session only and never shows it again.
That key has a space in it. Copy it again — keys never contain spaces.
